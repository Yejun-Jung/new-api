# Toilet Spot 🚻
카카오맵 API와 공공 데이터를 연동한 화장실 위치 정보 서비스입니다.

## 📌 프로젝트 소개
전국의 공공 화장실 데이터를 지도 위에 시각화하고, 실시간 검색 및 즐겨찾기 기능을 제공합니다.

## ⚙️ 주요 기능
- 카카오맵 마커 렌더링 및 상세 정보(인포윈도우) 표시
- 키워드 기반 실시간 검색 및 리스트 필터링
- Context API 전역 상태 관리 및 LocalStorage 활용 즐겨찾기 저장

## 🛠 사용 기술
- React / React Router DOM
- Kakao Maps API
- Tailwind CSS / Vite
